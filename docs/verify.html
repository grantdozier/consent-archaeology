WHAT'S ACTUALLY HAPPENING

You clicked a link we emailed you. This page is sending the one-time token from that link back to our server, which checks it and — if it's valid — hands this browser tab a session token.

Cryptographically, that is the entire ceremony. It proves you control that inbox, which is the only thing standing between "privacy tool" and "people-search engine with mood lighting." So we treat one email click like a state occasion. That's the joke. It's also the actual security model.

Once verified, you may run a sweep on exactly one person: you. There is no mode where you look up someone else. There is no admin bypass. The gap between this site and a stalking tool is this page, so this page does not bend.

The session lives in this tab and ends when you close it. The link itself is single-use — if you need another, the intake form issues a fresh one.
